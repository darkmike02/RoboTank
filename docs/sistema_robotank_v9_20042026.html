Diagnóstico del sistema — versión 20/04/2026

Análisis completo del código fuente. Se revisaron 28 archivos Python.

✅ Correcciones aplicadas (vs versión anterior)
BUG-001 RESUELTO — Cinemática inicializada
self.iniciar_cinematica() está correctamente al final del __init__() de Robot, fuera de cualquier otro método. La IK se inicializa en cada arranque.
BUG-003 RESUELTO — Sin métodos duplicados
pinza_abrir(), pinza_cerrar() y saludo() están definidos una sola vez en robot_controller.py. No hay sobreescritura silenciosa.
OFFSET_SHOULDER = 50 ✓
config_robot.py tiene OFFSET_SHOULDER = 50, valor validado físicamente el 01-Feb-2026 (PWM horizontal = 0° matemático).
PID implementado en mission_loop
ACERCANDO_P1 y ACERCANDO_P2 usan control PID (Kp=2.5, Ki=0.01, Kd=0.5) con anti-windup en lugar de velocidad fija. Mejora la precisión de frenado.
Parche de inversión de codo documentado
robot_controller.py aplica codo_corregido = 270 - angulos['codo'] antes de enviar la señal al servo. Corrige la dirección física del servo 2.
Vision Engine mejorado
Lógica dual: detección por área grande (>5000px bypass) + filtro espacial estándar (rojo sobre azul). Morfología MORPH_CLOSE para objetos brillantes.
⚠️ Issues activos que requieren atención
API Key expuesta en main_server.py línea 14
genai.configure(api_key="AIzaSyCJ...") — clave de Google en texto plano. Mover a variable de entorno: os.environ.get('GEMINI_API_KEY').
OFFSET_ELBOW = 135 — distinto al valor histórico
Los protocolos del 01-Feb-2026 validaron OFFSET_ELBOW = 36 (codo recto). El valor actual es 135. Con el parche de inversión (270 - codo) esto puede compensarse, pero conviene documentar por qué cambió.
pausa_tactica() bloquea el hilo con input()
El método pausa_tactica() en mission_loop llama a input() — esto congela el proceso completo en producción. Es útil en modo DEBUG pero debe desactivarse para ejecución autónoma real.
background_telemetry() bloquea SocketIO con Gemini
La llamada a modelo_ia.generate_content() en el bucle de telemetría tarda 2-4s y bloquea el hilo de SocketIO. La telemetría se congela durante ese tiempo. Solución: threading.Thread separado.
CameraStream sin reconexión automática
Si libcamera-vid muere, get_frame() devuelve None indefinidamente sin reintentar. Añadir: if self.process.poll() is not None: self.__init__().
test_calibrador.py con importación rota
Intenta import robot_controller (ruta raíz) pero en V9 el módulo está en drivers/. El fallback con importación relativa también puede fallar al ejecutarse como script standalone.
MODO_RASTREO_ROJO nuevo en esta versión
main_server.py añade un tercer estado cognitivo: seguimiento visual por OpenCV a 20Hz activado/desactivado por voz. El hilo cv_tracking_loop() corre en background_task separado.
calibrador_distancia.py — script de diagnóstico nuevo
Toma foto estática con libcamera-jpeg a 10cm y analiza máscaras HSV rojo/azul. Útil para depurar el problema de pérdida de objeto en proximidad.

Demás scripts de test — descripción

Scripts de diagnóstico y calibración. No ejecutar durante operación del servidor principal.

test_vision.py
Prueba aislada de VisionEngine + CameraStream. Imprime en consola si detecta objeto rojo (cx, cy, area) a 10Hz. Sin movimiento de hardware.
Visión · HITO 1
test_vision_debug.py
Captura foto estática con libcamera-jpeg, aplica máscaras HSV rojo/azul, detecta contornos y analiza si el par rojo-sobre-azul pasa el filtro espacial. Guarda debug_vision.jpg con anotaciones.
Diagnóstico visual
test_navigation.py
Prueba NavigationEngine en bucle a 10Hz. El robot avanza con v=100 y frena si el sensor detecta obstáculo a menos de 20cm. Incluye cuenta regresiva de seguridad.
Navegación · HITO 2
test_brazo.py
Secuencia de captura manual: abre garra → baja a (15,0,0) → cierra garra → sube a (10,0,20). Cuenta regresiva de 3s. Verifica la IK en hardware real.
IK · HITO 4
test_calibracion_ik.py
Mueve el brazo a 10 coordenadas predefinidas e interactivamente pide al usuario medir la posición real con una regla. Genera reporte JSON con error (dx, dy, dz) en cada punto.
Calibración IK
test_calibrador.py
Calibrador PID interactivo. Busca el PWM mínimo que vence la fricción, luego ejecuta control PID en tiempo real hacia objetivo de 28cm. Permite ajustar Kp, Ki, Kd desde la terminal sin reiniciar.
PID · calibración
test_camera.py
Captura 10 frames con CameraStream y reporta el tamaño en bytes de cada uno. Verifica que libcamera-vid esté funcionando y el buffer llegue correctamente a Python.
Hardware · cámara
test_integracion_drivers.py
Smoke test de importaciones. Importa Robot() y lo instancia. Si no hay errores, el paquete drivers/ está correcto. Es el primer test a ejecutar tras un cambio de arquitectura.
Integración · imports
buscar_camara.py
Escanea los 16 canales del PCA9685 enviando pulsos 60°→120°→90°. Sirve para identificar qué canal está conectado a qué servo físico.
HW · mapeo servo
calibrador_distancia.py
Toma foto estática a 10cm con libcamera-jpeg y analiza máscaras HSV. Diagnostica si el problema es pérdida del azul (pedestal oculto) o pérdida del rojo (sombra/desenfoque). Guarda máscara como imagen.
